## Simple Interest Calculator

The `simple-interest.sh` script calculates simple interest using:

Simple Interest = Principal × Rate × Time / 100

## Usage

Make the script executable:

```bash
chmod +x simple-interest.sh
```

Run it:

```bash
./simple-interest.sh
```
